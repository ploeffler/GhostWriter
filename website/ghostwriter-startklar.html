So einfach ist GhostWriter bereit für dich.

Von der GitHub-Anmeldung bis zu deinem ersten Startprompt im Chat.

Du brauchst einen Platz für deine Bücher und einen KI-Assistenten, mit dem du arbeiten möchtest. GitHub bewahrt deine Dateien und ihre Änderungen auf. Dein Chat führt dich durch die Bucharbeit. Hier bereitest du beides Schritt für Schritt vor.

Für regelmäßige Bucharbeit dringend empfohlen: die Bezahlversion deines KI-Assistenten.

Nutze möglichst einen passenden kostenpflichtigen Tarif des Anbieters, mit dem du ohnehin arbeiten möchtest. Die Bezeichnung ist nicht überall „Pro“. Prüfe vor dem Abschluss die aktuellen Nutzungsgrenzen, Datei-Funktionen und GitHub-Möglichkeiten. Ein Abo allein garantiert keinen schreibenden Zugriff auf dein Repository. Du brauchst dafür nicht drei KI-Abos.

1 · Melde dich bei GitHub an

Öffne GitHub. Hast du bereits ein Konto, melde dich dort an. Sonst wähle Sign up, folge der Registrierung und bestätige deine E-Mail-Adresse. Falls GitHub eine zusätzliche Prüfung verlangt, erledigst du sie selbst auf der GitHub-Seite.

Dein Ziel: Du bist bei GitHub angemeldet und kennst deinen Benutzernamen.

Passwörter, Bestätigungscodes und geheime Zugangsschlüssel gehören in den jeweiligen Anmeldedialog, nicht in deinen Buchchat.

GitHub-Hilfe: Konto erstellen

2 · Hol dir deine eigene GhostWriter-Kopie

Öffne die GhostWriter-Vorlage. Dein Manuskript kommt später in deine eigene Kopie, nicht in dieses öffentliche Programmrepository.

  1. Wähle Use this template → Create a new repository.
  2. Wähle dein eigenes GitHub-Konto als Owner.
  3. Gib einen Namen ein, zum Beispiel meine-buecher.
  4. Wähle Private, damit deine Buchdateien nicht öffentlich sichtbar sind.
  5. Lass Include all branches ausgeschaltet und bestätige Create repository from template.

Ein „Repository“ ist hier einfach dein Projektordner auf GitHub. Die Vorlage bringt die Programmdateien bereits mit. Kopiere anschließend die Adresse deiner eigenen Kopie, etwa https://github.com/DEINNAME/meine-buecher.

Dein Ziel: Du hast ein eigenes privates Repository und seine Adresse griffbereit.

Was ist mit Updates und GitHub Actions?

Öffne in deinem eigenen Repository den Bereich Actions und prüfe, ob Workflows ausgeführt werden dürfen. Für die einmalige Einrichtung sieht GhostWriter den Lauf GhostWriter aktualisieren → Run workflow vor. Warte auf den erfolgreichen Abschluss; ein fehlgeschlagener Lauf ist noch kein abgeschlossenes Update.

Die vollständige Anleitung erklärt auch den optionalen Zugang für Workflow-Datei-Updates. Ohne diesen bleiben diese Dateien bei Updates unverändert; andere Programmdateien können trotzdem aktualisiert werden. Trage geheime Schlüssel nur in die vorgesehenen GitHub-Secret-Felder ein.

3 · Verbinde den Chat, den du nutzen möchtest

Melde dich bei deinem KI-Anbieter an. Wähle deine vorhandene Chat-Anwendung und stelle dort den Zugriff auf deine GhostWriter-Kopie her. Beschränke den Zugang auf dieses Repository, soweit die Verbindung diese Auswahl anbietet.

Wichtig: Dateien im Chat zu sehen und Änderungen auf GitHub speichern zu können sind zwei verschiedene Fähigkeiten. Eine reine Dateiübernahme reicht für das gemeinsame Planen; automatisches Speichern braucht zusätzlich passende Werkzeuge und Rechte.

Ich nutze ChatGPT oder Codex

Suche in deiner verwendeten OpenAI-Anwendung nach der verfügbaren GitHub-App beziehungsweise dem GitHub-Plugin und verbinde dein Konto über den angebotenen Anmeldedialog. Falls ein Arbeitsbereich beteiligt ist, kann die Freigabe durch dessen Verwaltung nötig sein. Wähle deine eigene GhostWriter-Kopie aus.

ChatGPT, Codex und ihre verschiedenen Oberflächen bieten nicht automatisch dieselben Werkzeuge. Lass im nächsten Schritt prüfen, ob diese Sitzung Dateien tatsächlich lesen und auch Änderungen speichern kann. Eine Verbindung in einer anderen Oberfläche ist kein Nachweis dafür.

OpenAI: Computer und Apps verbinden · OpenAI: Codex Cloud und GitHub

Ich nutze Claude

In der dokumentierten Chat-Oberfläche wählst du + → Add from GitHub. Melde dich bei Aufforderung bei GitHub an und erlaube den Zugriff auf deine private Kopie. Wähle zunächst die Einstiegsdateien, insbesondere README.md und START.md.

Die eingebaute Dateiintegration liefert Kontext. Behandle sie nicht automatisch als Schreibverbindung. Lass die tatsächlich verfügbaren Werkzeuge prüfen; falls das Speichern fehlt, kannst du zunächst im Chat planen und Ergebnisse später selbst übertragen.

Claude: GitHub-Integration verwenden

Ich nutze Gemini

Die dokumentierte Web-Oberfläche bietet am Computer Add file → More Uploads → Import code. Gib dort die Adresse deines Repositorys ein. Für ein privates Repository verknüpfst du bei Aufforderung dein berechtigtes GitHub-Konto.

Dieser Import ist eine Momentaufnahme: spätere Repository-Änderungen werden nicht automatisch nachgeladen. Die GitHub-App von Gemini schreibt laut Anbieterhilfe nicht ins Repository und liest es auch nicht allein aufgrund eines Links im Prompt. Importiere daher vor dem Start die Dateien. Für das Speichern nutzt du eine gesondert unterstützte Schreibverbindung oder überträgst die Ergebnisse selbst.

Gemini: GitHub-Repository importieren

Dein Ziel: Dein ausgewählter Chat kann auf die Einstiegsdateien zugreifen – über eine Verbindung oder einen bewussten Dateiimport.

4 · Öffne deinen vorbereiteten Chat

Öffne einen neuen Chat in der Anwendung, die du verwenden möchtest. Aktiviere die GitHub-Verbindung beziehungsweise füge den Repository-Import hinzu. Halte die Adresse deiner eigenen GhostWriter-Kopie bereit.

Du brauchst keinen zusätzlichen Prüfauftrag und musst die GhostWriter-Regeln nicht selbst in den Chat kopieren. Sie stehen bereits in START.md.

Dein Ziel: Dein Chat und die Adresse deines Repositorys sind bereit.

5 · Starte GhostWriter mit nur einem Prompt

Ersetze die Beispieladresse durch dein eigenes Repository und sende diesen einen Satz:

Lies die Datei START.md aus dem Repo https://github.com/DEINNAME/meine-buecher

START.md enthält den Einstieg und die Arbeitsregeln. Beim Laden dieser Datei prüft der Assistent nach diesen Vorgaben den Repository-Zugriff und die ohne Änderung erkennbaren Berechtigungen. Dafür brauchst du keinen zweiten Prompt. Das bloße Öffnen dieser HTML-Anleitung stellt noch keine Verbindung her.

Fehlt der Zugriff, erklärt der Assistent, was noch einzurichten ist. Bei einem reinen Dateiimport muss START.md im importierten Material enthalten sein; der Repository-Link allein ersetzt den Import nicht.

Wird dabei auch der Schreibzugriff geprüft?

Ja: GhostWriters Startregeln sehen vor, die verfügbaren Werkzeuge und Berechtigungen ohne Dateiänderung zu prüfen. Ein Schreibtest durch Anlegen oder Ändern einer Datei gehört nicht zum Start.

Dass Speichern tatsächlich funktioniert, bestätigt erst die erste ausdrücklich beauftragte und erfolgreich ausgeführte Speicherung. Fehlt die Schreibmöglichkeit, kann GhostWriter zunächst im Chat weiterarbeiten und Ergebnisse zum eigenen Übertragen ausgeben.

Du musst diesen Check nicht zusätzlich anfordern. Er gehört zum Ablauf aus START.md.

Woran erkennst du, dass es losgeht?

GhostWriter erkennt dein Repository und führt dich nach seinen Startregeln weiter. Eine vorbereitete Bibliothek zeigt ihr Bücherregal, auch wenn noch kein Buch darin steht. Über Neues Buch beginnt anschließend die Buchanlage. Die dafür ausdrücklich bestätigte Anlage ist vom späteren Speichern der ausgearbeiteten Buchstruktur getrennt.

Über Neues Buch gibst du anschließend deinen ersten Arbeitstitel an.

Du brauchst noch keine fertige Handlung. Thema, Zielgruppe, Stil und Gliederung entwickelt ihr im Gespräch.

GhostWriter ist bereit für deine erste Idee.
