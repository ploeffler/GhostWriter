Programming through conversation

Programming with AI is this simple.

Describe what you want. Build an HTML page together with AI.

A saved conversation shows how a question became a first book draft. Now it is to become a small HTML page, with navigation, styling and a print layout. The author describes his wishes in everyday language; the AI handles the implementation. In the recorded workflow, he does not enter any program code himself.

1 · Describe your starting point

I had an idea/research written down locally an hour or two ago

The first search finds planning notes, then a different research chat. The author clarifies:

the chat was saved in the local folder ... something about creating a book

This leads to the local source package “Von antiken Fabeln zum Kinderbuch”: the saved conversation, the chapter drafts and notes on using the material later.

Before AI builds something, it needs to know what to work with. Clarification and corrections are part of the process.

2 · Describe the result you want

can we turn this chat into something like "it's this simple"? I'd have the book to go with it

The existing material now has a new purpose. Instead of reproducing the entire chat, a short example should show the key steps: the initial idea, choosing characters, planning the book, requesting the draft and seeing the result.

GhostWriter proposes five steps. Short quotations show which decisions came from the author. Editorial explanations connect them into a readable story.

You do not need technical terminology yet. A concrete wish is enough to start developing a structure together.

3 · Have a first version built

can you implement that locally already? the file is coming shortly

The conversation is enough to prepare a first version. GhostWriter creates a local text source with five steps, eight original quotations and a comparison of the starting idea and the result at the time.

The book pages are still missing. Their place is prepared without inventing a book preview. The historical draft remains distinct from the book supplied later.

4 · Let AI write the code

great! is there an HTML version too?

The content becomes a coded page. AI writes the HTML and CSS: HTML organises headings, quotations and tables; CSS controls colours, spacing and the layout on wide or narrow screens. Step navigation and a print layout are added.

AI also creates a small Python script to turn the text source into HTML. After text changes, the page can be generated again. The finished file opens locally in a browser without external fonts or scripts.

Your request is a sentence. It becomes actual files and runnable code you can keep and develop locally.

5 · Open, review and improve

GhostWriter checks the original quotations, links and HTML structure. An automated visual browser check does not work in this environment; this limitation is reported.

The author opens the file himself and replies:

check ok

The page has now received the author's visual feedback. The book file is still missing at this point. Later, he provides it and real book pages are added.
