# 3.8 Übung: Mein Mini-Start-Plan

## Ziel des Abschnitts

Offen.

## Kurzbeschreibung

Offen.

## Recherche- und Brainstorming-Ergebnisse

Werden in separaten Laufdateien dokumentiert.

## Manuskript

Nimm dir zehn Minuten.

1. **Aufgabe wählen:** Eine konkrete Aufgabe, die dich beschäftigt.
2. **Hürde benennen:** Was genau macht den Start schwer? Unklarheit, Größe, Unlust, Angst vor dem Ergebnis?
3. **Ersten Schritt festlegen:** So klein, dass er in unter zwei Minuten passt.
4. **Auslöser setzen:** „Wenn ___, dann ___.“
5. **Hilfe einplanen:** Sichtbarer Hinweis, Body Doubling, Timer, Belohnung.
