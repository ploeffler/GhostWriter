# 1.8 Übung: Meine Etiketten

## Ziel des Abschnitts

Offen.

## Kurzbeschreibung

Offen.

## Recherche- und Brainstorming-Ergebnisse

Werden in separaten Laufdateien dokumentiert.

## Manuskript

Nimm dir zehn Minuten. Ein Zettel oder dein Handy reicht.

1. **Sammeln:** Welche Etiketten kenne ich? Von wem habe ich sie gehört?
2. **Übersetzen:** Was könnte dahinterstecken? Nutze die Tabelle weiter oben als Anregung.
3. **Prüfen:** Wann stimmt das Etikett nicht? In welchen Situationen funktioniere ich gut?
4. **Neu benennen:** Wie würde ich das Muster beschreiben, ohne es zu bewerten?

| Etikett | Von wem? | Was könnte dahinterstecken? | Wann stimmt es nicht? |
| --- | --- | --- | --- |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

Du musst nichts davon „richtig“ ausfüllen. Es geht ums Beobachten, nicht ums Urteilen.
