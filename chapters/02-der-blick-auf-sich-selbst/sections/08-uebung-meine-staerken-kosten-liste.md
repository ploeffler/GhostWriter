# 2.8 Übung: Meine Stärken-Kosten-Liste

## Ziel des Abschnitts

Offen.

## Kurzbeschreibung

Offen.

## Recherche- und Brainstorming-Ergebnisse

Werden in separaten Laufdateien dokumentiert.

## Manuskript

Nimm dir zehn bis fünfzehn Minuten.

1. **Sammeln:** Schreibe drei Eigenschaften auf, die du an dir schätzt oder die andere an dir mögen.
2. **Gegenseite:** Was kostet dich jede davon manchmal?
3. **Rahmen:** In welchen Situationen hilft dir die Eigenschaft? Wo steht sie dir im Weg?
4. **Ableiten:** Wie könnte ich mir im Alltag mehr von der ersten Hälfte und weniger von der zweiten gönnen?

| Eigenschaft | Was sie mir bringt | Was sie mich kostet | Wo ich sie gezielt einsetzen kann |
| --- | --- | --- | --- |
|  |  |  |  |
|  |  |  |  |
|  |  |  |  |

Eine zweite, kürzere Übung für schwerere Tage: Schreibe zwei Spalten, eine mit „Was ich vermisse“ und eine mit „Was ich trotzdem geschafft habe“. Es geht nicht darum, die Trauer wegzurechnen, sondern beides sichtbar zu machen.
