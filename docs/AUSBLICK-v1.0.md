# Das nächste Kapitel wird groß.

**Mehr Gestaltung. Mehr Möglichkeiten. Dein Buch im Mittelpunkt. GhostWriter nimmt Kurs auf 1.0.**

Figuren zum Leben erwecken, Bilder dort einsetzen, wo sie wirken, aus einer Gestaltungsvorlage einen Umschlag entwickeln: Bis 1.0 soll aus den vorhandenen Grundlagen ein durchgehend geprüfter Weg zum fertigen Buch werden. Hier siehst du, welche Etappen dafür vorgeschlagen sind.

> **Ausblick, keine Verfügbarkeitszusage:** Die folgende Versionsfolge ist ein Planungsvorschlag. Die zentrale Dokumentationswebsite einschließlich Aufbau und Veröffentlichung ist v0.9.0 zugeordnet. Die übrige Zwischenversionsfolge ist noch nicht beschlossen. Genannte Erweiterungen sind Ziele, keine bereits verfügbaren Funktionen; Veröffentlichungstermine sind nicht zugesagt.
