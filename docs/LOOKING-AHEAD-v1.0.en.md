# The next chapter is getting bigger.

**More creative control. More possibilities. Your book at the centre. GhostWriter is heading towards 1.0.**

Bring characters to life, place images where they matter and turn a design reference into a cover: the aim for 1.0 is a thoroughly tested path from the existing foundations to a finished book. These are the proposed stages along the way.

> **A preview, not a promise of availability:** The release sequence below is a planning proposal. The central documentation website, including its build and publication, is assigned to v0.9.0. The remaining intermediate release sequence has not been approved. The extensions described here are goals, not features already available; no release dates are promised.

## The road to 1.0

| Stage | What to look forward to |
|---|---|
| **v0.6.1 · A firm foundation** | Create a book · edit text · save safely · clear approvals |
| **v0.6.2 · Pick up where you left off** | Switch chats · recognise the latest version · back up conversations · restore work |
| **v0.7.0 · Give your book a face** | Character references · illustrations · graphics · image sources · separate image approval |
| **v0.7.1 · Every image in its place** | Choose image position · resize with a slider · text wrapping · output preview |
| **v0.7.2 · Your design. Your cover.** | Upload a cover · use a design reference · adjust the cover · print and e-book |
| **v0.8.0 · Bring your manuscript along** | Import a manuscript · keep its structure · spot formatting losses · preserve the original |
| **v0.8.1 · See the bigger picture** | Check characters, style and continuity · see cited passages · choose suggestions to apply |
| **v0.9.0 · Find your way. Get writing.** | German/English · clear terms · honest cost and limit information · searchable documentation |
| **v1.0.0-rc.1 · Make it all work together** | Test the full book journey · check updates · preserve book data · verify recovery |
| **v1.0.0 · Ready for your next chapter** | Verified feature scope · clear release notes · explicitly approved publication |

**The direction is clear: more room for your book, with reliable steps towards publication.** Every stage needs implementation and acceptance. Passing tests alone does not publish a release.
