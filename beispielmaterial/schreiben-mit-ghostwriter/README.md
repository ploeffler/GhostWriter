# Schreibpraxis / Writing practice

Freigegebenes abstrahiertes Fallbeispiel. Deutsche Texte und Layout: `erzeugen.py`; englische Inhalte: `english.py`. Zwölf statische Seiten, drei ausdrücklich erfundene Dialogbeispiele je Sprache. Keine Originalgespräche, privaten Manuskripte oder Verweise auf das Quellbuch aufnehmen.

Approved abstracted case study. German text and shared layout: `erzeugen.py`; English content: `english.py`. Twelve static pages, with three explicitly fictional dialogue examples per language. Do not include original conversations, private manuscripts or links to the source book.

Neu erzeugen / Rebuild from the repository root:

```sh
python3 beispielmaterial/schreiben-mit-ghostwriter/erzeugen.py --publish
```

`--publish` bereitet nur `website/schreibpraxis/` lokal vor. Kein Upload. Die manuelle Pages-Action mit `documentation: true` erhält zusätzlich die zentrale Dokumentationswebsite. Verlinkung in beiden READMEs und beiden Website-Startseiten gemeinsam pflegen.

`--publish` only prepares `website/schreibpraxis/` locally. It does not upload. Run the manual Pages workflow with `documentation: true` to retain the central documentation website. Maintain the links in both READMEs and both website entry pages together.
